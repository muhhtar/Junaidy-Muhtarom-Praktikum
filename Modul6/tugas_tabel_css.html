Penjelasan Teknik CSS yang Digunakan

a. Inline Style

CSS langsung ditulis dalam atribut style pada tag HTML. Cocok untuk styling yang hanya digunakan sekali.

b. Class Selector

Dengan menggunakan titik (.) sebelum nama class. Dapat digunakan berulang kali pada banyak elemen.

c. ID Selector

Dengan menggunakan hashtag (#) sebelum nama ID. Hanya boleh digunakan sekali dalam satu halaman.

d. External CSS

CSS ditulis dalam file terpisah (.css) dan dihubungkan dengan tag <link>.
