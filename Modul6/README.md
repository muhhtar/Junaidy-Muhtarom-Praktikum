# Modul 6 - CSS (Cascading Style Sheets)

## Tugas Praktikum
1. Memahami teknik styling CSS: Inline, Internal, External
2. Menggunakan selector: Element, Class, ID
3. Menerapkan CSS pada tabel HTML
4. Membuat laporan dengan screenshot dan penjelasan

## File yang Dikumpulkan
1. `latihan1_css_dasar.html` - CSS dasar dengan element selector
2. `latihan2_css_class.html` - CSS dengan class selector
3. `latihan3_css_id.html` - CSS dengan ID selector
4. `tugas_tabel_css.html` - Tugas utama styling tabel
5. `styles.css` - File CSS eksternal
6. `linked_css.html` - Contoh penggunaan linked CSS

## Teknik CSS yang Dipelajari
### 1. Inline Style
CSS ditulis langsung dalam atribut `style` pada tag HTML.

### 2. Internal Style
CSS ditulis dalam tag `<style>` di bagian `<head>`.

### 3. External Style
CSS ditulis dalam file terpisah (.css) dan dihubungkan dengan `<link>`.

### 4. Selector
- **Element Selector**: `p { color: red; }`
- **Class Selector**: `.error { color: green; }`
- **ID Selector**: `#header { font-size: 24px; }`

## Hasil Pembelajaran
1. Dapat membuat tabel dengan berbagai teknik styling CSS
2. Memahami perbedaan antara inline, internal, dan external CSS
3. Dapat menggunakan class dan ID selector dengan tepat
4. Dapat membuat tampilan tabel yang menarik dan responsif
